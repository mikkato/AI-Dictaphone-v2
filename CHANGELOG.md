# AI-Диктофон — журнал релизов

## 2.1.2 (vc 7) — прод, 05.11.2026
Релизная сборка: R8 + shrinkResources, подпись `release.jks` (alias `dictaphone`), только arm64-v8a.

### Новое
- Шаблоны саммари возвращены в сокращённом виде: «Протокол» и «Звонок» (чипы выбора,
  привязка к промпту; `templateId` хранится в каждой версии саммари). БД: v2 → v3.
- Живой прогресс-бар генерации: детерминированный процент по map-фазе (фрагмент i из N),
  неопределённый индикатор при загрузке модели/ожидании API, плавная анимация,
  счётчик отстримленных символов, стриминг финального текста поверх.
- Markdown → plain text (`util/PlainFmt`): саммари отображается и копируется «как в
  текстовом редакторе» — заголовки ПРОПИСНЫМИ, списки «•», таблицы выровненными
  колонками, инлайн-разметка (`**`, `*`, `_`, `` ` ``, ссылки) снята. Сырой Markdown
  остаётся в БД; экспорт `.md` — по-прежнему Markdown.
- Экспорт `.txt` теперь включает секцию «САММАРИ» (plain text); `.json` получил поле
  `textPlain`. В меню заметки — «Копировать саммари» (plain text в буфер).
- Плеер: Play/±10 c/скорость перенесены в верхний ряд карточки — нижние кнопки больше
  не перекрываются информером.
- Информер (`MemInformer`) сворачиваемый: стрелка «Свернуть» → кружок-индикатор;
  тап по кружку разворачивает. Состояние сохраняется между перезаходами.

### Проверено
- Юнит-тесты: 25/25 зелёные (новые: снятие md-разметки, выравнивание таблиц).
- Эмулятор API 36 arm64: локальная генерация саммари end-to-end (Qwen3 0.6B q4_0),
  рендер plain text подтверждён скриншотом (капс-заголовки, «•», без следов `**`);
  цикл сворачивания/разворачивания информера; управление плеера в верхнем ряду.

## 2.1.0 (vc 5) — прод, 05.11.2026
Релизная сборка: R8 minify + shrinkResources, подпись `release.jks` (alias `dictaphone`), только arm64-v8a.

### Размер и скорость
- APK: 107 МБ → ~21 МБ (R8 + отказ от x86_64 + удаление неиспользуемых зависимостей).
- Удалены: `media3-ui`, `concurrent-futures`, `listenablefuture`, плагин `kotlinx-serialization` (не использовался).
- `gradle.properties`: parallel builds + build cache.
- Холодный старт: ленивые Keystore/EncryptedSharedPreferences в SettingsRepository (тема вынесена в обычные prefs).
- UI-тред разгружен: IPC памяти в `MemInformer` переведён на Dispatchers.IO.

### Исправления
- **WavParser**: ArrayIndexOutOfBoundsException при ресемплинге 48к→16к на записях длиннее ~65 с (guard читал кадр за границей окна). Плюс регрессионный юнит-тест (1.5 млн кадров через parseFile).
- **RecordingService / Android 16**: `startForeground(MICROPHONE)` перенесён внутрь сервиса с проверкой RECORD_AUDIO — устранён `ForegroundServiceStartNotAllowedException`; при отказе — корректный `stopSelf()`.
- **ModelDownloader**: HTTP-ошибки больше не проглатываются; корректная обработка 206/416 и сброс Range при ответе 200.
- **TranscriptionEngine**: убран O(n²) — на каждом чанке перетирались все сегменты БД; теперь дописывается только новый хвост.
- **jni_bridge.cpp**: удалён мёртвый колбэк `onProgress` (такого метода в Kotlin-интерфейсе нет).
- Уведомление записи: время через `TimeFmt.duration` вместо самодельного форматта.

### Проверено
- Юнит-тесты: 22/22 зелёные (включая новый регресс WavParser).
- Эмулятор API 36 (Android 16), arm64: запуск без крашей, полный цикл записи
  старт→пауза→продолжить→highlight→стоп, FGS `isForeground=true types=0x80`,
  WAV 76 с декодируется без крэша, транскрипция завершается корректным
  «Транскрипт пуст» (микрофон эмулятора беззвучный).

### Прод-файлы (не коммитить, chmod 600)
- `release.jks` + `keystore.properties` — приватный ключ подписи.
  Отпечаток сертификата (SHA-256): 25:81:71:DE:8C:0E:2F:D6:87:FF:F8:D2:47:5D:F1:86:F4:5C:E3:DA:66:86:B4:CE:CF:84:82:8A:42:34:26:94
  **Резервная копия ключа обязательна: без него нельзя выкатывать обновления.**
